
# Phishing URL Awareness Checker

## Overview
A beginner-friendly Python project that checks URL text for common phishing warning signs.

## Features
- Checks for the @ symbol.
- Checks URL length.
- Checks for IP addresses in the hostname.
- Checks for many hostname segments.
- Checks for punycode.
- Checks whether the URL uses HTTP.

## Requirements
- Python 3.10 or newer.
- No external packages required.

## How to Run
Open the project folder in VS Code and run:

python phishing_checker.py

## Testing
Tested using five sample URLs.

## Limitations
This tool only checks URL text. It does not visit websites or guarantee that a URL is safe.

## Ethical Use
Use this project for educational awareness and testing with sample URLs only.
